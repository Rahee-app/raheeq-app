# تطبيق رَحيق | Raheeq Mobile App

تطبيق هاتف ذكي (Cross-Platform Mobile App) مبني باستخدام **Flutter & Dart**، مخصص لتتبع الورد اليومي والعبادات والأذكار بواجهة هادئة ونظيفة (**Minimalist & Clean UI**)، بدون أي تعقيد أو إشعارات مزعجة، وخالٍ تماماً من أي نغمات أو أصوات (**Silent Mode**)، مع الاعتماد حصرياً على الاهتزاز الخفيف (**Haptic Feedback**) عند التفاعل.

---

## الهوية البصرية والتصميم (Visual Identity)

- **اللون الرئيسي (Primary Green)**: `#16652B` (الأخضر المعتمد في الهوية والشعار).
- **اللون التفاعلي (Accent Lime)**: `#DCF755` (الليموني الهادئ للنسب والمؤشرات).
- **الوضع الليلي (Dark Mode)**: `#121212` و `#1E1E1E` (فاحم مريح للعين).
- **الوضع النهاري (Light Mode)**: `#F7F8F9` و `#FFFFFF` (أبيض ناصع ونظيف).
- **أيقونة الملف الشخصي الرمزية (Profile Avatar)**:
  - 🔵 **أزرق هادئ للذكور**: `#3B82F6`
  - 🌸 **وردي هادئ للإناث**: `#EC4899`
- **الشعارات المعتمدة**: مدمجة بالكامل من مجلد `assets/images/` (`logo1.png`, `logo2.png`, `logo3.png`, `logo4.png`).
- **الخطوط**: خط `Cairo / Araboto` المتناسق للأرقام والنصوص العربية والإنجليزية.

## مميزات وشاشات التطبيق

1. **شاشة البداية (Splash Screen)**:
   - يظهر الشعار بمنتصف الشاشة مع حركة ناعمة وهادئة لمدة ثانيتين، ثم ينتقل تلقائياً لصفحة تسجيل الدخول أو الشاشة الرئيسية.

2. **شاشة تسجيل الدخول (Google Sign-In Only)**:
   - تسجيل دخول حصري عبر جوجل.
   - نص قانوني ومطمئن لسياسة الخصوصية.
   - نافذة منبثقة للسياسة التامة تعرض النص بالحرف:
     > *"نحن في التطبيق نؤمن بأن راحتك وخصوصيتك هما الأساس. نود إعلامك بكل شفافية أن تطبيقنا لا يطلب مطلقاً أي أذونات حساسة؛ فلا نطلب إذن الوصول إلى موقعك الجغرافي، ولا نطلب صلاحية الدخول إلى استوديو الصور أو الملفات، ولا نطلب أي وصول إلى الميكروفون أو التسجيل الصوتي. بيانات حسابك تستخدم فقط لتأمين وتخزين إنجازاتك اليومية بكل أمان، وراحة بالك هي غايتنا."*

3. **إعدادات البروفايل التلقائية (Profile Setup)**:
   - جلب الاسم تلقائياً من حساب جوجل.
   - تحديد الجنس لاختيار لون خلفية أيقونة البروفايل (زرقاء للذكور ووردية للإناث).

4. **الشاشة الرئيسية (Daily Timeline & Progress)**:
   - رأس الشاشة: شعار التطبيق + "مرحباً، [اسم المستخدم]" + أيقونة البروفايل الملونة.
   - مؤشر الإنجاز اليومي: دائرة ونسبة مئوية توضح المنجز (مثلاً 5 من 8).
   - قائمة الورد اليومي المرتبة زمنياً:
     1. صلاة الفجر
     2. ورد القرآن (صفحتين)
     3. أذكار الصباح
     4. صلاة الظهر
     5. صلاة العصر
     6. صلاة المغرب
     7. صلاة العشاء
     8. تسبيح لمدة دقيقة
   - اهتزاز خفيف (Haptic Feedback) عند الضغط على أي مهمة.
   - إعادة الضبط التلقائي: حفظ الإنجاز فور إتمام الـ 8 مهام والعودة للتصفير لبدء اليوم التالي بنظافة.

5. **شاشة الأذكار (Morning & Evening Adhkar)**:
   - قسمان منفصلان: (أذكار الصباح) و (أذكار المساء).
   - النصوص الدقيقة مأخوذة بنسبة 100% من الملفات المرفقة مع عدد التكرارات الدقيق.
   - كل ذكر في بطاقة مخصصة مع عداد تكرار و Checkbox يتلون ويهتز بنعومة عند الإنجاز.

6. **شاشة عداد دقيقة التسبيح (1-Minute Focus Tasbeeh)**:
   - شاشة هادئة بدون أي مشتتات.
   - عداد تنازلي مدته 60 ثانية.
   - زر لمس دائري كبير ومريح يغطي مساحة واسعة مع اهتزاز خفيف عند كل تسبيحة واهتزاز ختامي عند انتهاء الدقيقة.
   - تحديث حالة مهمة "تسبيح لمدة دقيقة" تلقائياً في الشاشة الرئيسية عند الانتهاء.

7. **شاشة السجل والالتزام (Streak & History)**:
   - عداد الأيام المتتالية (Current Streak).
   - إجمالي الأيام المنجزة وسجل التواريخ السابقة بأسلوب مريح بدون أي تأنيب ضمير.

8. **قائمة الإعدادات (Settings)**:
   - تعديل الاسم والجنس.
   - التبديل بين الوضع الليلي والصباحي (Dark / Light Mode).
   - تغيير لغة التطبيق (العربية / الإنجليزية) مع بقاء نصوص القرآن والأذكار باللغة العربية حصرياً.
   - زر التواصل عبر انستغرام `@raheeq.app` الذي يفتح حساب الانستغرام مباشرة.
   - قراءة سياسة الخصوصية.
   - تسجيل الخروج.

## هيكلية المشروع (Project Architecture)

```
Raheeq App/
├── assets/
│   ├── images/                # الشعارات الرسمية (logo1, logo2, logo3, logo4)
│   └── data/                  # ملفات JSON لأذكار الصباح والمساء
├── lib/
│   ├── constants/             # الألوان، الثيمات، النصوص، ومسارات الملفات
│   ├── models/                # نماذج البيانات (Task, Dhikr, UserProfile, History)
│   ├── services/              # خدمات التخزين، الاهتزاز، الأذكار، والمصادقة
│   ├── providers/             # إدارة الحالة عبر Provider
│   ├── widgets/               # المكونات التفاعلية والبطاقات
│   ├── screens/               # جميع شاشات التطبيق
│   └── main.dart              # نقطة انطلاق التطبيق
├── android/                   # إعدادات أندرويد
├── ios/                       # إعدادات آيفون
└── pubspec.yaml               # ملف الحزم والمكتبات
```

## خطوات التشغيل والبناء (Run & Build Commands)

### 1. تثبيت الحزم (Install Dependencies)
```bash
flutter pub get
```

### 2. تشغيل التطبيق في وضع التطوير (Run Debug Mode)
```bash
# تشغيل على الجهاز المتصل أو المحاكي (Android / iOS)
flutter run
```

---

### 3. أوامر بناء نسخة أندرويد (Android Build)

#### أ) استخراج ملف APK جاهز للتثبيت المباشر:
```bash
# ملف APK موحد لجميع المعالجات (Release APK)
flutter build apk --release

# أو استخراج ملفات APK مقسمة حسب المعمارية لتقليل حجم التطبيق:
flutter build apk --split-per-abi --release
```
> ستجد ملف الـ APK الناتج في المسار:  
> `build/app/outputs/flutter-apk/app-release.apk`

#### ب) استخراج ملف حزمة متجر جوجل بلاي (App Bundle):
```bash
flutter build appbundle --release
```
> ستجد الملف في المسار:  
> `build/app/outputs/bundle/release/app-release.aab`

---

### 4. أوامر بناء نسخة آيفون (iOS Build)

> يتطلب جهاز Mac مثبت عليه Xcode.

#### أ) تجهيز وتحديث ملفات Pods:
```bash
cd ios
pod install
cd ..
```

#### ب) استخراج ملف التوزيع (IPA / Archive):
```bash
# بناء حزمة الـ iOS Release
flutter build ipa --release
```
> بعد انتهاء البناء، يمكنك فتح مجلد `ios/Runner.xcworkspace` عبر Xcode لرفع التطبيق مباشرة إلى App Store Connect أو TestFlight.
